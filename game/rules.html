Three skills

  • 01 Code — Null Protocol
  • 02 Canvas — Golden Confection
  • 03 Heart — Glass Elevator
  • Code — ship truth, break scams, pass the packet.
  • Canvas — taste, composition, factory beauty.
  • Heart — empathy, social skill, human connection.

How a run works

  1. Enter a tribute name (local only — not an account).
  2. Engine draws 15 sealed trials (5× Code · Canvas · Heart) from a larger bank.
  3. Skills interleave; within each lane, difficulty trends easier → harder.
  4. Single choice or ordered sequence. Keys 1–4 select; Enter locks in.
  5. Finish → verdict, local board write, optional share card. Re-deal on retry.

No runtime eval. Answers sealed as keys/indices. Sound optional (off by default).

Ranks

WORTHY

Factory Confectioner — overall ≥75% and every skill ≥65%. Path toward team consideration still goes through The Games & Wonka — not a job offer.

TRIBUTE

Active Tribute — solid overall or two sharp lanes (≥70% skill mark); one lane still soft.

DANGER

Danger zone — mid pack (~45%+ overall without Tribute bar). Another weak trial and you’re glass-side.

MELT

Melted chocolate — train the three skills and re-enter.
